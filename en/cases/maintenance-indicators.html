Case · Analytics Engineering

Reproducible maintenance indicators.

Python pipeline to clean Qsystems exports, build a final table in Google Sheets and feed operational monitoring dashboards in Looker Studio.

View dashboard Repository

Outcome

Final source Sheets
Process Python ETL
Output Operational BI

Problem

  • Qsystems did not support custom indicators and segmentations.
  • Each update required Excel exports, cleanup and manual merging.
  • The manual process created friction and inconsistency risk.
  • Adding new rules meant reworking spreadsheets.

Solution

Qsystems exports Excel files for orders, locations and owners Google Drive centralizes source files Google Colab runs pandas ETL and quality rules Google Sheets receives the final fac_ordenes table Looker Studio consumes consistent data for indicators
